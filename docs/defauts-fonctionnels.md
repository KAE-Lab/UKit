# Défauts fonctionnels connus

Registre court des défauts de COMPORTEMENT encore ouverts (le goût et le design n'y entrent pas). Un défaut rencontré en chemin s'inscrit ici avec la date et le symptôme observé, et NE SE CORRIGE PAS au passage, sauf s'il tombe exactement dans le périmètre du travail en cours : mêler fonctionnel et visuel rend le travail invérifiable. Un défaut corrigé est supprimé d'ici ; son histoire reste dans git (commits, et tag `doc-v1` pour l'ancienne version détaillée : `git show doc-v1:docs/defauts-fonctionnels.md`). Des commentaires du code peuvent citer ce fichier pour un défaut aujourd'hui corrigé. `[P]` = plausible (mesure ou rapport, rejouable sur appareil seulement), `[V]` = vérifié dans le code.
